# Open Questions

**Related documents:** every document in `docs/` — this file is deliberately a cross-cutting index of unresolved items, pulled from BRD, FRD, FSD, design-handoff, and the rest of the Product Owner package, rather than a new source of gaps invented for this document.

---

## What this is and how to keep it alive

This is the first thing an incoming Product Owner should read after the Product Goal, and the thing they should update most often. Every item below was flagged as undecided somewhere in the existing documentation — this file exists to stop those flags from staying scattered and easy to forget. **Review this list at every retrospective** (`docs/product-owner/working-cadence.md`); resolved items move to the "Resolved" table at the bottom with the decision and its date, rather than being deleted — a decision log is worth as much as a question log.

Each item includes a **suggested lean** where I have one, based on the reasoning already documented elsewhere in this package. A suggested lean is not a decision — it's there so the Product Owner is disagreeing with a stated position, not starting from a blank page.
